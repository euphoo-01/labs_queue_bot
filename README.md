# Labs Queue Bot (Google Sheets & grammy.js)

Телеграм-бот для организации живой очереди на сдачу лабораторных работ. В качестве базы данных использует Google Таблицы.

## Основная идея

Бот помогает автоматизировать и упорядочить очередь студентов на сдачу лабораторных работ. Приоритет в очереди отдается тем, у кого меньше всего отметок о сдаче.

**Ключевая механика:**
-   **Источник данных:** Бот подключен к Google Таблице, где в объединенных строках (количество предметов) перечислены студенты, следующей колонкой - предметы, а в колонках — даты занятий (генерируются автоматически).
-   **Формирование очереди:** Когда студент запрашивает очередь по предмету, бот анализирует таблицу, подсчитывает количество отметок ("сдано") у каждого и выстраивает очередь, поднимая вверх тех, у кого сдано меньше работ.
-   **Отметка о сдаче:** С помощью команд студент может отметить, что он сдал работу, и бот поставит соответствующую пометку в ячейку таблицы.

## Функционал и команды

-   `/start` — Приветственное сообщение и краткая инструкция.
-   `/queue [предмет]` — Показать актуальную очередь по указанному предмету.
-   `/queue [предмет] [id_пользователя]` — Отметить, что вы сдали лабораторную работу по предмету, или подходили ее сдавать, но не сдали.
-   `/skip [предмет] [id_пользователя]` - Отметить, что был на лабораторной работе, но не пошел сдавать лабораторную

## Технологии

-   **Фреймворк:** grammy.js (JavaScript)
-   **База данных:** Google Sheets API]
-   **Платформа:** Telegram
-   **Хостинг:** Vercel (с использованием вебхуков)

## Установка и развертывание

### Шаг 1: Настройка проекта

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/euphoo-01/labs_queue_bot.git
    cd labs_queue_bot
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

### Шаг 2: Настройка Google Sheets API

1.  **Создайте Google Таблицу:**
    -   Создайте новую таблицу. Первая колонка должна содержать имена студентов, а последующие — названия предметов.
    -   Скопируйте ID таблицы из URL (например, `.../spreadsheets/d/THIS_IS_THE_ID/edit`).

2.  **Создайте сервисный аккаунт в Google Cloud:**
    -   Перейдите в Google Cloud Console
    -   Создайте новый проект.
    -   В разделе "APIs & Services" -> "Enabled APIs & services" включите **Google Sheets API**.
    -   Перейдите в "Credentials", нажмите "Create Credentials" -> "Service account".
    -   Заполните данные, выдайте роль "Editor" (Редактор) и создайте ключ в формате JSON. Сохраните этот файл.
    -   Скопируйте email созданного сервисного аккаунта.

3.  **Предоставьте доступ к таблице:**
    -   Вернитесь в вашу Google Таблицу.
    -   Нажмите "Share" (Поделиться) и вставьте email сервисного аккаунта, выдав ему права редактора.

### Шаг 3: Настройка переменных окружения

Создайте файл `.env` в корне проекта и заполните его по аналогии с `.env.example`:

```env
# Токен вашего бота из @BotFather
BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"

# ID вашей Google Таблицы
GOOGLE_SHEET_ID="YOUR_GOOGLE_SHEET_ID"

# Данные из JSON-файла сервисного аккаунта
GOOGLE_SERVICE_ACCOUNT_EMAIL="xxx@yyy.iam.gserviceaccount.com"
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"

# URL вашего приложения на Vercel (добавляется автоматически при деплое)
VERCEL_URL="your-app-name.vercel.app"
```

### Шаг 4: Развертывание на Vercel

1.  **Зарегистрируйтесь на Vercel** с помощью вашего GitHub-аккаунта.
2.  **Создайте новый проект** и импортируйте этот репозиторий.
3.  **Настройте переменные окружения** в настройках проекта на Vercel, скопировав их из вашего `.env` файла.
4.  **Запустите Deploy.** Vercel автоматически определит тип проекта, установит зависимости и развернет его.
5.  После успешного развертывания Vercel предоставит вам URL. Бот, настроенный на работу с вебхуками, автоматически зарегистрирует этот адрес в Telegram.
